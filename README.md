# Ezra

Portal logístico estático publicado via GitHub Pages.

## Link de acesso

- URL principal: https://whitebeto.github.io/Ezra/
- URL direta do arquivo: https://whitebeto.github.io/Ezra/portal-logistico.html

## Configuração necessária no GitHub

1. Acesse `Settings` → `Pages` no repositório.
2. Em `Build and deployment`, selecione `Source: GitHub Actions`.
3. Aguarde a execução do workflow **Deploy static site to GitHub Pages**.

Após o deploy concluir, o site ficará visível e acessível pelos links acima.
